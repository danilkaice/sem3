О приложении

Название: Система учета сотрудников

Версия: 1.0

Разработчик: Зеленовский Д.М.

Описание: Веб-приложение для учета сотрудников и их адресов с разграничением доступа по ролям (READ_ONLY, USER, ADMIN). Реализован расчет годовой премии, управление ролями, логирование в файл.

Технологии: Spring Boot 2.7.8, Spring Security, Spring Data JPA, Thymeleaf, H2, Lombok, Actuator, Bootstrap 5.
